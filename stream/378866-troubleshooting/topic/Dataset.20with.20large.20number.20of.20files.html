Philip Durbin 🚀 (Sep 03 2026 at 11:26):

I'm happy to hear what others think but in the guides we suggest avoiding many files: https://guides.dataverse.org/en/6.11/admin/big-data-administration.html#avoiding-many-files

The solutions I'm aware of:

  • Putting the files in a zip file instead (and probably making sure the zip previewer/downloader is installed so files can be downloaded individually).
  • Splitting the dataset into multiple datasets.
