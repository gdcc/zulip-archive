Topic: Uploaded thumbnail images are not shown in Dataverse v6.11

Juan (Sep 02 2026 at 14:37):

There is a behavioral difference between Dataverse v6.5 and Dataverse v6.11 that appears to be a bug. After uploading a thumbnail image to a dataset, it cannot be viewed from either the dataset page or the dataverse page.

This issue occurs because getThumbnailUrl() in Dataset.java checks that thumbnailFile is not null:

public String getThumbnailUrl() {
    return thumbnailFile != null ? SystemConfig.getDataverseSiteUrlStatic() + "/api/datasets/" + this.getId() + "/logo" : null;
}

However, after uploading a thumbnail image, thumbnailFile is explicitly set to null:

Java

public Dataset setNonDatasetFileAsThumbnail(Dataset dataset, InputStream inputStream) {
[....]
    dataset = DatasetUtil.persistDatasetLogoToStorageAndCreateThumbnails(dataset, inputStream);
    dataset.setThumbnailFile(null);
    dataset.setUseGenericThumbnail(false);
    return merge(dataset);
}

I think that the getThumbnailUrl() method should check !useGenericThumbnail instead of thumbnailFile != null.

Philip Durbin 🚀 (Sep 02 2026 at 16:22):

Juan (Sep 02 2026 at 21:36):

Yes, sure. Before these changes , the file was accessed from the ThumbnailServiceWrapper.java without checking the contents of thethumbnailFile variable.
String url = SystemConfig.getDataverseSiteUrlStatic() + "/api/datasets/" + dataset.getId() + "/logo";

Now, it checks for null first in the Dataset.java file:
return thumbnailFile != null ? SystemConfig.getDataverseSiteUrlStatic() + "/api/datasets/" + this.getId() + "/logo" : null;
