Topic: Spreadsheet previewer issues when locally installed

Deirdre Kirmis (Sep 14 2026 at 18:34):

Hi .. we are running dataverse v6.11 .. we recently installed the previewers locally since that is recommended and we were having some issues with CORs .. I'm noticing that with files that are ingested to tabular format .. whether they already existed, or if I upload an .xlsx file and it gets ingested .. the spreadsheet previewer appears next to the file but it does not work/display anything. (It acts like it is going to preview but nothing is there). If I disable ingestion and upload an .xlsx file no previewer appears next to the file, which I know is expected.

The filetype on the uningested file is "MS Excel Spreadsheet" and the filetype on the ingested file is "Tab-Delimited". All of the other previewers are working as expected. We have the recommended CORs on the bucket permissions and JVM options. Any ideas on why the spreadsheet viewer would invoke but not display anything?

Deirdre Kirmis (Sep 14 2026 at 18:37):

More testing reveals that this is related to the header " Header always set X-Content-Type-Options nosniff" .. I believe that is a good header to have .. Is there a way around it?

Deirdre Kirmis (Sep 14 2026 at 18:42):

.. nosniff makes the browser refuse to run the JavaScript library that reads CSV/TSV-style spreadsheet data because Apache is serving that library as text/plain, so the spreadsheet previewer loses its parser and renders blank

Deirdre Kirmis (Sep 14 2026 at 19:24):

update: i was able to copy dataverse-previewers/previewers/v1.5/papaparse@5 to papaparse@5.js and change the reference in SpreadsheetPreview.html to that and that fixed it .. in case anyone comes across this
