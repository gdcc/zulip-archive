What does this PR do?

It splits the current integration tests into 3 groups that take about the same time to run.

This PR causes 6 GitHub Action runners to run concurrently at the same time, but it pushes down the entire process from PR to test results in about 20-25 minutes flat.

Build Containers ──┬── JSF Tests (chromium) ~ 20 mins
├── JSF Tests (firefox) ~ 23 mins
├── JSF Tests (webkit) ~ 21 mins
└── Integration Tests (Group 1) ~ 18 mins
└── Integration Tests (Group 2) ~ 18 mins
└── Integration Tests (Group 3) ~ 18 mins

So overall this is a very major improvement for development speed.

So, what's the catch? Well, GitHub Free Organizations (like IQSS) have a concurrency limit of 20 runners for the WHOLE org. So this means at max 3 PRs can be processed every 20 minutes for all repos within the org. I linked some numbers onto the PR.
