Ash Manda (Oct 11 2026 at 01:06):

Here's what it fixes:

  • Containers built twice per commit. The JSF and API test workflows each did their own build. Now one build is handed off to all the test jobs.
  • JSF browsers ran one after another, and a Chromium failure meant Firefox and WebKit never ran. Each browser now has its own job, and they run in parallel.
  • Expensive re-runs. A flaky test meant re-running the whole ~50-minute workflow. Now you re-run just the failed job, on the saved build.
  • CI failures couldn't be reproduced. The exact images a run tested against can now be downloaded and started locally.
  • No code coverage since Jenkins. Every run now produces a JaCoCo report (HTML + XML) of what the API and JSF tests exercise on the server: about 51% of lines so far.

Each browser job also runs the full API test suite against the same installation, so every commit gets three independent runs of the API tests under real UI load, which is good for catching flaky tests.

Push to green: ~50 → ~42 min. The tests themselves are unchanged.
