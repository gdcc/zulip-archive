Topic: Submit for Review settings don't support multiple languages

César Ferreira (Nov 10 2026 at 16:27):

Hi, we recently updated our Dataverse installation to version 6.11 and we were trying to configure the settings :SubmitForReviewDatasetDisclaimerText and :DatasetSubmitForReviewPopupCustomText but these settings don't support the configuration for multiple languages. I have tried to configure with the endpoint /api/admin/settings/$setting/lang/$lang but it didn't work. I searched in the release notes for 6.12 and 6.12.1 and I didn't find any mention about this problem.

I was trying to make some changes in the source code using this method and in my experiments I noticed that the method used to get a setting key with a language parameter was deprecated in version 6.9 and is marked for removal. Any plans on removing the option to configure multiple languages for a setting, or is there a different method that I am missing?
