Ash Manda (Sep 24 2026 at 19:13):

The installing R section requires some prereqs that don't appear in the doc and will fail for anyone trying to set up R. I would consider this a mission-critical path as tabular ingest for .R files will not go through without R installed. We have hit this issue before where not having R installed would block all kinds of uploads that included an R file. This may cause the installation to fail silently.

I am going to include some commands that helped me

Ash Manda (Sep 24 2026 at 19:15):

sudo dnf install -y \ gcc \ gcc-c++ \ make \ cmake \ autoconf \ automake \ openssl-devel \ libcurl-devel \ libxml2-devel \ zlib-devel \ bzip2-devel \ xz-devel \ R-core \ R-core-devel

This is the list of prereqs you would require to install the R libraries. Usually on a normal dev system, this would be masked by sudo dnf groupinstall "Development Tools"

Ash Manda (Sep 24 2026 at 19:16):

Command to install the packages:
sudo Rscript -e ' pkgs <- c("R2HTML", "rjson", "DescTools", "Rserve", "haven") install.packages( pkgs, repos = "https://cloud.r-project.org/", lib = "/usr/lib64/R/library", Ncpus = parallel::detectCores() ) '

Command to test the packages installed:
Rscript -e ' pkgs <- c("R2HTML", "rjson", "DescTools", "Rserve", "haven") results <- sapply(pkgs, require, character.only = TRUE, quietly = TRUE) print(results) if (!all(results)) { cat("\nFailed to load:", names(results)[!results], "\n") quit(status = 1) } else { cat("\nAll R packages verified successfully.\n") } '
