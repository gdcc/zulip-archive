Topic: Switch from mod_proxy_ajp to mod_proxy_http

Deirdre Kirmis (Sep 03 2026 at 23:29):

Hi all .. I've been meaning to ask this question and now it's kind of urgent ..

We are running Dataverse 6.11 on Payara 7 with the standard Apache + mod_proxy_ajp + Shibboleth configuration from the installation guide. We are occasionally seeing mod_proxy_ajp BufferOverflowException / ajp_marshal_into_msgb: Error appending the header value errors during Shibboleth-authenticated requests, resulting in a 400 Bad Request before the request reaches Payara. Our institution's IdP is known to send relatively large SAML-derived headers, and we've previously had to work around header-size issues by stripping cookies on /shib.xhtml.

Has anyone successfully migrated a Dataverse 6.x installation from mod_proxy_ajp to mod_proxy_http with Shibboleth? If so, were there any Dataverse- or Shibboleth-specific configuration changes required beyond updating the Apache proxy configuration?
